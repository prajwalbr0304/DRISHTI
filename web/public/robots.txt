# DRISHTI — crawler policy
#
# Vite copies public/ verbatim into dist/, so this file ships to Catalyst Slate
# and is served at /robots.txt (it previously returned 404).
#
# Only two routes are publicly reachable: "/" (the landing page) and "/login".
# Everything else in web/src/App.tsx sits behind <RequireAuth>. Because the
# Slate SPA catch-all rewrites every path to /index.html with HTTP 200, those
# app routes would otherwise be crawled as endless duplicates of the landing
# page — hence the explicit Disallow list below. index.html also carries
# <link rel="canonical"> back to "/" as a second line of defence.

User-agent: *
Allow: /$
Allow: /login
Allow: /drishti.svg
Allow: /product/
Allow: /landing/

# Authenticated application surface — no public content behind these.
